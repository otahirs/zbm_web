<p>Vítejte na&nbsp;stránkách brněnských areálů pevných kontrol, které mají za&nbsp;cíl přiblížit přírodu lidem a&nbsp;lidi přírodě. Areál pevných kontrol je síť 10&nbsp;až&nbsp;15 trvale osazených kontrolních stanovišť v&nbsp;terénu, ke&nbsp;kterým se dostanete pomocí speciální mapy, jakou využívají příznivci orientačních sportů &ndash; a&nbsp;dostanete se tak do&nbsp;míst, kam by Vás běžné putování lesem asi nezavedlo. Vyzkoušejte si to, kvůli čemu příznivci orientačních sportů brázdí svět. Kontroly můžete absolvovat v&nbsp;libovolném pořadí a&nbsp;v&nbsp;libovolném počtu.</p>
<p><b>Náš klub postupně přechází k&nbsp;projektu <a href="https://www.venku.app/" target="_blank">Venku.app</a>.</b> Venku.app je mobilní aplikace, se&nbsp;kterou kontrolní stanoviště najdete přímo v&nbsp;terénu bez&nbsp;nutnosti tisknout si mapu &ndash; stačí aplikaci stáhnout do&nbsp;telefonu a&nbsp;vyrazit do&nbsp;lesa. Areál, u&nbsp;kterého už přechod proběhl, je níže označen a&nbsp;popsán zvlášť; ostatní areály zatím fungují po&nbsp;staru s&nbsp;mapou ke&nbsp;stažení v&nbsp;PDF, se&nbsp;kterou se hodí přibalit si i&nbsp;buzolu.</p>
<p>V&nbsp;dohledné době přibude i&nbsp;možnost tisku mapy a&nbsp;kontrol pro&nbsp;Venku.app.</p>
<p>Základy, co to ten orienťák vlastně je a&nbsp;legendu k&nbsp;mapě, můžete nalézt na&nbsp;webu <a href="https://zacitorientak.cz/brno/co-to-je/190" target="_blank">zacitorientak.cz</a>. Přehled areálů pevných kontrol, o&nbsp;které se stará náš klub, je k&nbsp;dispozici níže. Pokud se vám hledání kontrol zalíbí, můžete si orientační běh vyzkoušet i v&nbsp;jiných koutech České republiky &ndash; přehled všech českých areálů pevných kontrol naleznete <a href="https://zacitorientak.cz/brno/zkusit/190#pevne-kontroly" target="_blank">zde</a>. </p>
<p><b>Přejeme Vám neobvyklé zážitky při hledání kontrolních stanovišť a příjemný pobyt v&nbsp;brněnských lesích. </b></p>
